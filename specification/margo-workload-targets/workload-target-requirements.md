# Workload Target Requirements Supplemental Material

The following content supplements the [Device Requirements](https://docs.margo.org/specification/margo-devices/device-requirements) documentation in the core specification with requirements clarifications specific to workload targets supporting the Compose deployment technology.

Workloads supporting the Compose deployment technology MUST provide the following additional components:

- Ability to deploy Compose files
- An OCI container runtime, for example, Docker or Podman
